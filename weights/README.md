# Weights (not published)

The base checkpoint (a YOLO26n-seg model, Ultralytics 8.4.22, 22 class slots, one trained class) is not public. It and every checkpoint derived from it (`eel_1cls.pt`, `eel_1cls_no_s32.pt`, `eel_v2.pt`, `wise_*.pt`, `v2_blend_*.pt`, `mask_refiner.pt`) are not in this repository.

The scripts write their checkpoints here. `docs/REPORT.md`, section "Reproducibility", gives the order in which they build `eel_v2.pt`.
